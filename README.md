# GK Watcher

GK Watcher is a tool built on Vite and React for automatically scraping Japanese websites, mostly for GKs, and emailing you when new items are found.

Run `./deploy.sh` or `deploy.bat` once to install dependencies, run checks, and build the client. Then run `./start.sh` or `start.bat` to start GK Watcher. The backend starts automatically on port 3000.

From a Git checkout, run `./update.sh` or `update.bat` to pull and verify the latest version.
